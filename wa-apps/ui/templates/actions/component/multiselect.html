Множественный выбор с поиском и тегами выбранных значений на основе <select multiple>. Исходный <select> хранит значения, участвует в отправке и валидации формы.

Локальный поиск и форма

Поддерживаются атрибуты optgroup, selected, disabled, required. Поиск фильтрует текст без учёта регистра. Выбор значений вызывает событие change; сброс формы восстанавливает начальные значения.

{_render_multiselect} 
{_render_multiselect|escape}

Клавиатура

  • Enter, пробел и стрелки ↓↑ раскрывают список.
  • Стрелки ↓↑ перемещают выделение по списку.
  • Enter выбирает выделенное значение.
  • Esc очищает поле поиска. Если это поле пустое, то закрывает список и возвращает фокус.
  • Tab закрывает список и переводит фокус дальше.

Асинхронный поиск

Метод .load(query) возвращает одиночный массив или массив объектов вида {literal}{ value: "1", text: "Анна", disabled: false }{/literal}. Значение — строка или число, подпись — строка, необязательный атрибут disabled — boolean. Дубликаты значений отбрасываются. Поиск запускается с задержкой 250 мс, устаревшие ответы игнорируются. Постраничная навигация не используется.

Пример обращения к серверу

Введите «ошибка», чтобы получить состояние ошибки или неизвестное имя — для демонстрации получения пустого результата. Начальные выбранные значения задаются с помощью атрибута <option selected>.

Локализация

Укажите нужные тексты вместо стандартных в свойстве locales. Язык по умолчанию — русский.

{literal}$("#items").waMultiselect({
    locales: {
        placeholder: "Select values",
        searchPlaceholder: "Search",
        loading: "Loading…",
        empty: "No results",
        error: "Unable to load results",
        remove: "Remove"
    }
});{/literal}

Стандартные значения: «Выберите значения», «Поиск», «Загрузка…», «Ничего не найдено», «Не удалось загрузить список», «Удалить». Подписи отображаются в виде текста.

Значения, события и методы

{literal}var $select = $("#items").waMultiselect();
var instance = $select.waMultiselect("multiselect");

$select.on("change", function() { console.log($(this).val()); });
$select.val(["a"]).trigger("change");

instance.open();
instance.close();

// После изменения option, disabled или классов элемента select:
instance.refresh();

// Перед удалением компонента, в том числе при закрытии диалога:
instance.destroy();{/literal}

Повторная инициализация возвращает jQuery-коллекцию и сохраняет существующий экземпляр. Метод destroy() восстанавливает исходный <select>, удаляет панель, обработчики и данные экземпляра. Перед удалением HTML-разметки из DOM вызывайте .destroy() самостоятельно.

В диалоге

Панель добавляется в <body> и позиционируется относительно окна таким образом, чтобы не обрезаться контейнером диалога. При нехватке места снизу список открывается вверх.
